# GPT Image 2.0 생성기 가이드

## 1. 모델 개요/스펙

- 모델명: `gpt-image-2` / GPT Image 2.0.
- 출시 맥락: 2026년 4월 공개된 OpenAI 2세대 이미지 생성·편집 모델로, 새 워크플로의 기본 이미지 모델 1순위로 사용한다.
- 강점: 네이티브 Thinking 모드(2차 자료 기반 리서치 메모 — 공식 보증 아님), 포토리얼리즘, 편집 안정성, 인물·아이덴티티 보존, 구조화된 시각물, 한글을 포함한 텍스트 렌더링.
- 텍스트: 리서치 기준 95%+ 정확도를 목표로 사용할 수 있다는 주장은 2차 자료 기반 리서치 메모이며 공식 보증이 아니다. 정확한 문구는 반드시 따옴표로 지정하고 소형·밀집 텍스트는 재검수한다.
- 참조 이미지: 최대 16개까지 역할을 나누어 사용할 수 있다.
- 해상도: 네이티브 4K급 출력을 지원하되, 2K 초과 영역은 실험적으로 취급한다. 실무 기본은 저품질/중간품질 원본 생성 후 필요한 경우 업스케일러를 붙이는 방식이 안전하다.
- 구독/사용 전제: 기본 이미지 모델은 전체 ChatGPT 사용자 대상, Thinking·웹검색·멀티이미지 기능은 Plus/Pro 이상 전제로 다룬다는 가용성 정보는 2차 자료 기반 리서치 메모이며 공식 보증이 아니다. 이 프로젝트에서는 OAuth 구독 CLI 사용을 전제로 하며 API 키 기반 독립앱 설계는 범위 밖이다.

## 2. 최적 프롬프트 템플릿(섹션별)

GPT Image 2.0은 키워드 더미보다 사진가·아트디렉터가 쓰는 자연어 브리프에 강하다. 아래 순서를 기본 템플릿으로 사용한다.

```text
Subject:
[주 피사체. 인물/제품/브랜드 요소/외형 고정 단서]

Action:
[피사체가 하는 행동, 시선, 손동작, 제품 상호작용]

Scene:
[장소, 시간대, 배경, 문화적 맥락, 사용 목적]

Composition:
[프레이밍, 앵글, 렌즈감, 심도, 배치, 여백, 종횡비]

Lighting:
[광원 방향, 질감, 대비, 색온도, 분위기]

Style:
[사진/광고/에디토리얼/렌더/일러스트 등 매체와 마감]

Text Constraint:
[이미지 안에 들어갈 정확한 문구는 반드시 따옴표로 작성. 폰트 성격, 위치, 크기, 정렬, 추가 텍스트 금지 조건]

Constraints:
[워터마크 없음, 추가 오브젝트 없음, 로고/얼굴/레이아웃 보존, 과도한 장식 금지]
```

편집 프롬프트는 반드시 `Change / Preserve / Constraints`로 분리한다.

```text
Change:
[바꿀 요소만 구체적으로 작성]

Preserve:
[얼굴, 아이덴티티, 포즈, 조명, 프레임, 배경, 텍스트, 로고, 레이아웃 등 유지할 요소를 명시]

Constraints:
[no extra objects, no redesign, no watermark, no extra text, change only the requested area]
```

## 3. 필수 포함 요소 체크리스트

- [ ] 주 피사체가 한 문장 안에 선명하게 정의되어 있다.
- [ ] 행동/포즈/시선/손 위치가 필요한 만큼 지정되어 있다.
- [ ] 장면의 장소, 시간대, 배경 맥락, 사용 목적이 포함되어 있다.
- [ ] 앵글, 렌즈감, 프레이밍, 심도, 여백 또는 종횡비가 지정되어 있다.
- [ ] 조명 방향, 색온도, 대비, 분위기가 지정되어 있다.
- [ ] 스타일은 “고품질” 같은 추상어가 아니라 매체·마감·질감으로 설명되어 있다.
- [ ] 이미지 안 텍스트는 정확한 문구를 따옴표로 감싸고, 위치와 타이포그래피를 지정했다.
- [ ] 편집 요청이면 Change와 Preserve가 분리되어 있으며, 보존 대상에 얼굴/로고/텍스트/레이아웃이 빠지지 않았다.
- [ ] 금지 조건은 짧고 행동 가능한 문장으로 적었다.

## 4. 금기

- 키워드 스팸: “8K, masterpiece, ultra detailed, trending, cinematic, beautiful” 같은 형용사 나열만으로 구성하지 않는다.
- 제너릭 표현: “멋진 광고 이미지”, “프리미엄 느낌”처럼 판단을 모델에 떠넘기지 않는다.
- 스톡사진/클립아트 느낌: 과한 미소, 무표정한 배경, 인위적 포즈, 과도한 보케만 의존하지 않는다.
- 과도한 그라데이션·장식 요소: 배너, 제품 광고, 썸네일에서 불필요한 빛줄기·반짝임·추상 장식을 기본값으로 넣지 않는다.
- 편집 Preserve 누락: 얼굴, 로고, 텍스트, 레이아웃을 명시하지 않으면 드리프트가 생긴다.
- 텍스트 모호화: “타이틀을 넣어줘” 대신 정확한 문구를 따옴표로 쓴다.
- 4K 남용: 2K 초과는 실험적으로 보고, 중요한 결과물은 낮은 해상도에서 구도 검증 후 업스케일한다.
- 캔디드/실사 스냅 레지스터를 기본 밀도로 요청: gpt-image-2는 기본값이 폴리시드 피부·정돈 구도·클리셰 포즈로 수렴한다(2026-07-08 실측). 캔디드 컷은 `core/style-library/candid-realism.md`의 gpt 보정 레버 4종(필름 트리트먼트 전면 그레인, 마이크로리얼리즘 피부, 미인화 역차단, 포즈 강제 분화)을 반드시 적용한다 — 레버 적용 시 nano-banana-pro 동급 이상까지 올라옴이 실측으로 확인됐다.
- 배치 생성(n>1)에서 포즈 다양성 기대: 한 프롬프트로 n장을 뽑으면 전 장이 같은 포즈로 수렴한다(실측 6/6). 포즈 다양성이 필요하면 포즈만 다른 문안으로 나눠 생성한다.

## 5. 인물 고정 수단

1. 참조 이미지를 첨부한다. 가능하면 정면 얼굴, 3/4 얼굴, 전신, 표정 또는 의상 참조를 역할별로 나눈다.
2. 참조 이미지는 최대 16개까지 사용 가능하나, 아이덴티티가 중요할수록 “어떤 이미지가 무엇을 제어하는지”를 짧게 라벨링한다.
3. Preserve 리스트에 `identity`, `face geometry`, `skin tone`, `hairline`, `hairstyle`, `eye shape`, `nose`, `mouth`, `jawline`, `age`, `recognizable likeness`를 반복 명시한다.
4. 외모 디테일을 자연어로 병행 서술한다. 참조 이미지만 믿지 말고 얼굴형, 헤어, 피부 톤, 고유 마커를 텍스트로 잠근다.
5. 매 편집마다 Preserve 리스트를 다시 적는다. “same person as before”만으로는 누적 편집에서 얼굴·로고·텍스트가 흔들릴 수 있다.
6. 스타일 참조가 얼굴을 바꾸지 않도록 “style reference affects lighting/color only, not identity”처럼 역할 제한을 넣는다.

## 6. 예시 프롬프트 1개(인물 마케팅 도메인)

```text
Subject:
참조 이미지 1의 동일한 한국인 여성 창업자. 30대 중반, 부드러운 타원형 얼굴, 자연스러운 검은 단발, 차분한 눈매, 오른쪽 볼의 작은 점, 실제 피부 결을 유지한다.

Action:
친환경 스킨케어 제품을 한 손에 들고 카메라를 향해 편안하게 미소 짓는다. 다른 손은 밝은 원목 테이블 위에 자연스럽게 올려둔다.

Scene:
서울의 미니멀한 브랜드 스튜디오. 배경에는 식물과 리필 가능한 유리 용기가 흐릿하게 보이며, 신제품 런칭 캠페인용 세로형 마케팅 비주얼이다.

Composition:
4:5 세로 포스터, 허리 위 미디엄 샷, 눈높이 카메라, 50mm 렌즈 느낌, 얕은 심도. 인물은 우측 1/3에 배치하고 좌측 상단에 헤드라인을 위한 넓은 여백을 둔다.

Lighting:
카메라 왼쪽의 큰 소프트박스와 창가 자연광이 섞인 부드러운 조명. 따뜻한 뉴트럴 톤, 피부 하이라이트는 과하지 않게, 제품 라벨은 선명하게 보인다.

Style:
프리미엄 K-뷰티 에디토리얼 광고 사진. 깨끗한 색보정, 자연스러운 피부 질감, 절제된 소품, 스톡사진 느낌 없이 실제 브랜드 촬영처럼 보이게 한다.

Text Constraint:
좌측 상단 헤드라인은 정확히 "피부가 쉬는 시간"이라고 렌더링한다. 얇고 현대적인 산세리프 한글 폰트, 크림색 텍스트, 자간은 넓게, 철자 오류 없이 선명하게. 다른 텍스트는 추가하지 않는다.

Constraints:
참조 이미지 1의 얼굴, 아이덴티티, 얼굴 기하, 피부 톤, 헤어라인, 헤어스타일, 눈·코·입·턱선, 나이, 인식 가능한 닮음을 보존한다. 제품 로고와 라벨 비율을 유지한다. 추가 인물, 추가 제품, 워터마크, 랜덤 로고, 과도한 그라데이션, 클립아트 장식, 얼굴 리디자인 없음.
```
