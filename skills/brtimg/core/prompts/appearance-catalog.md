# 인물 커스터마이징 카탈로그 (appearance-catalog)

이 문서는 캐릭터 시트의 `appearance` 필드를 게임 캐릭터 커스터마이징처럼 프리셋 선택으로 작성하는 축 카탈로그다. `core/prompts/character-sheet.md` 절차의 선택형 진행에 사용하며, GUI 빌더의 인물 탭과 공유한다.

## 1. 원칙

- 프롬프트는 언어이므로 수치 슬라이더가 아니라 **카테고리 프리셋**을 쓴다. 프리셋은 시작점이고, 각 축에서 자유 서술로 대체할 수 있다.
- 선택 결과는 프리셋 나열이 아니라 자연문으로 합성해 시트 필드에 넣는다. 합성 문장은 `persona-marketing.md` 2.1의 외모 구체성 규칙을 따른다.
- 모든 축은 패스 가능하다. 패스한 축은 시트에서 생략한다(추정 금지 — `character-sheet.md` 2절).
- 실존 인물 복제 금지 규칙(`character-sheet.md` 3절)이 항상 우선한다.

## 2. guided 진행 방식 (4라운드)

1. 라운드 1 — 골격: 나이대·성별 표현, 얼굴형, 광대·턱선, 체형.
2. 라운드 2 — 이목구비: 눈 형태, 눈썹, 코, 입술.
3. 라운드 3 — 피부·헤어: 피부 톤·질감, 헤어 길이·컬·컬러·스타일·가르마·잔머리.
4. 라운드 4 — 마커·마감: 고유 마커, 안경, 액세서리, 기본 의상, 인상 키워드.

라운드 종료 후 합성 문장과 `signatureFeatures` 후보 2~4개를 보여주고 확정받는다.

## 3. 축 카탈로그

### 3.1 골격

- 나이대: 10대 후반 / 20대 초·중·후반 / 30대 초·중·후반 / 40대 / 50대+ .
- 얼굴형(표준 7종): 계란형(oval) / 둥근형(round) / 각진형(square, 턱선 뚜렷) / 하트형(heart, 이마 넓고 턱 뾰족) / 다이아몬드형(diamond, 광대 최광) / 긴형(oblong) / 삼각형(triangle, 턱이 최광).
- 광대: 부드럽게 살아 있음 / 도드라짐 / 평평함.
- 턱선: 갸름한 V라인 / 부드러운 곡선 / 각진 직선 / 뾰족한 턱.
- 체형: 마른 / 슬림 탄탄 / 중간 균형 / 곡선형 / 근육형 / 통통한. 키 느낌: 작음 / 중간 / 큼. 자세: 곧은 / 편안한 / 당당한.

### 3.2 이목구비

- 눈 형태(표준 8~10종): 아몬드 / 둥근 눈 / 후디드(눈꺼풀이 덮임) / 무쌍(monolid) / 올라간 눈꼬리(upturned, 캣아이) / 처진 눈꼬리(downturned) / 깊은 눈(deep-set) / 돌출 눈 / 몰린 눈(close-set) / 벌어진 눈(wide-set).
- 눈 크기·인상: 큰 눈 / 중간 / 작은 눈. 눈동자 색: 짙은 갈색 / 갈색 / 헤이즐 / 검정 / 회갈색 / 블루 / 그린. 속눈썹: 선명함 / 자연스러움. 언더아이: 부드러움(애교살) / 매끈함.
- 눈썹: 일자 / 아치형 / 부드러운 곡선 / 짙음 / 옅음.
- 코: 콧대 곧음 / 낮고 부드러움 / 오똑함 / 둥근 코끝 / 콧등 주근깨.
- 입술(표준 형태): 도톰(full) / 하트형(중앙 도톰) / 얇은 / 둥근(폭 좁고 원형) / 보우형(큐피드 보우 뚜렷) / 아랫입술 도톰. 마감: 매트 / 글로시·젤리 하이라이트 / 자연스러운 촉촉함. 색: 누드 베이지 / 핑크 베이지 / 로즈 / 코랄 / 레드 / 그라데이션 지정.

### 3.3 피부·헤어

- 피부 톤: 밝고 반투명 / 밝은 웜 / 라이트 미디엄 / 미디엄 / 태닝 / 딥. 언더톤: 웜 / 쿨 / 뉴트럴.
- 피부 질감: 자연 결·모공 보임 / 매끄럽고 정제됨(모공 최소) / 촉촉 광 / 세미매트 / 주근깨 / 홍조.
- 헤어 길이: 숏컷 / 단발(턱선) / 어깨 길이 / 어깨 아래 / 롱 / 매우 긴.
- 컬 타입(1~4): 생머리(Type 1) / 웨이브(Type 2) / 컬리(Type 3) / 코일리(Type 4). 굵기: 가는 모 / 중간 / 굵은 모.
- 컬러: 블랙 / 블루블랙 / 다크브라운 / 브라운 / 로즈브라운 / 애쉬 / 블론드 / 하이라이트·발레아쥬 / 비비드(핑크·블루 등).
- 스타일: 풀어 내림 / 낮은 포니테일 / 높은 포니테일 / 번(묶음) / 하프업 / 땋음 / 올림머리.
- 가르마·앞머리: 가운데 가르마 / 옆 가르마 / 시스루 뱅 / 풀 뱅 / 이마 노출.
- 잔머리: 볼선을 따라 얇게 내려옴 / 정돈됨 / 자연스럽게 흐트러짐. 헤어라인: 둥근 / 각진 / M자형.

### 3.4 마커·마감

- 고유 마커(2~4개 선택, 반드시 위치 명시): 점(볼·입가·눈가·콧등·눈밑·목) / 주근깨(콧등·볼) / 보조개 / 흉터 / 치아 틈 등 치아 특징.
- 안경: 없음 / 얇은 금속 프레임 / 뿔테 / 반무테 / 형태(원형 / 타원 / 사각 / 타원·사각 혼합 / 캣아이) / 렌즈(투명 / 틴트) / 템플 디테일.
- 액세서리: 스터드 귀걸이 / 링 귀걸이 / 드롭 귀걸이 / 목걸이 / 헤어핀 / 시계 / 안경 체인 / 피어싱 / 스카프 / 없음.
- 기본 의상(`wardrobeDefaults`): 니트 카디건 / 린넨 셔츠 / 블라우스 / 슈트 / 티셔츠 / 원피스 / 스트랩 디자인(색 지정) 등 + 색·소재.
- 인상 키워드(표정 기본값, `persona-marketing.md` 2.2 변환 규칙 적용): 차분한 자신감 / 신뢰감 / 활기 / 고급스러움 / 차갑고 절제됨 / 친근함.

## 4. 시트 필드 매핑

| 축 | 캐릭터 시트 필드 |
| --- | --- |
| 얼굴형·광대·턱선 | `appearance.face` |
| 헤어 길이·컬·컬러·스타일·가르마·잔머리·헤어라인 | `appearance.hair` |
| 눈 형태·크기·속눈썹·언더아이·눈썹 | `appearance.eyes` |
| 피부 톤·질감 + 입술 형태·색 | `appearance.skin` (입술은 face에 넣어도 됨 — 한쪽에만) |
| 체형·키 느낌·자세·나이대 | `appearance.build` |
| 고유 마커·안경·액세서리 중 정체성 판정용 2~4개 | `appearance.signatureFeatures` |
| 인상 키워드·용도 + 시각 유지 항목 | `identityAnchors` |
| 기본 의상 | `wardrobeDefaults` |
| 마커 누락 금지 등 | `negativeConstraints` |

## 5. 정합 규칙

1. 무쌍(monolid)과 "뚜렷한 쌍꺼풀" 계열 서술은 동시 선택 불가.
2. 후디드 눈 + "뚜렷한 아이라인 강조"는 실제로 가려지므로 확인 후 진행.
3. 안경을 선택하고 `signatureFeatures`에 넣었으면 `negativeConstraints`에 "안경 제거 금지"를 자동 추가한다.
4. 잔머리·시스루 뱅 등 헤어 디테일은 시리즈 컷 간 흔들리기 쉬우므로, 선택 시 `identityAnchors`에 유지 문구를 넣을지 확인한다.
5. 마커 없이 확정하려 하면 경고한다 — 마커 없는 시트는 컷 간 동일 인물 판정이 약해진다.

## 6. 자가점검 3항목

1. 스키마 매핑: 선택값이 4절 매핑대로 필드에 들어갔고 나열이 아닌 자연문인가.
2. 마커 품질: `signatureFeatures`가 위치 포함 2~4개이고 `negativeConstraints`에 누락 금지가 있는가.
3. 재현성: 프리셋 조합만 읽고 제3자가 같은 인물을 그릴 수 있는가.
