# 스토리보드 스킬 (storyboard) — 서사 영상 파이프라인 2단계

수집일: 2026-07-08. 근거: 페이블5(힉스필드 MCP) 스킬 산출물 22장 실물 분석(workspace/fable5-skills/ 아카이브, 애니메·픽사 3D·사이버펑크·실사 메카 등 9개 프로젝트 공통 구조). 서사 영상은 단발 클립 프롬프트가 아니라 **캐릭터 시트 → 스토리보드 → 컷별 클립 생성 → 합본** 순서의 파이프라인으로 만든다. 스토리보드가 영상 생성보다 반드시 선행한다.

## 1. 산출물 규격 — 단일 이미지 12컷 그리드

스토리보드는 이미지 생성기(gpt-image-2 — 텍스트 렌더 통제가 필요하므로 GPT 라우팅)로 만드는 **단일 이미지**다.

- 상단 제목 헤더 1행: `[컨셉명] - [장면명] / [총길이] [컷수] ([캐릭터명, 조명·무드]) - [오디오 방침]`
  - 예 형식: "ANIME OP - ONE TAKE CHASE / 12 CUTS (DOMA, GOLDEN HOUR) - NO CUT, NO BGM" / "... / 15 SEC 12 CUTS (SUNSET BACKLIGHT, IMPACT MULTI-CAM, BGM + SFX)"
- 부제 1행: 카메라 연속성 선언 — 원테이크면 `ONE CONTINUOUS SHOT - camera never cuts, it ...` 형태로 카메라가 장면을 관통하는 경로를 한 문장으로.
- 본문: 4×3 12컷 그리드, 각 컷은 ①번호 원문자 ②장면 일러스트 ③캡션 3필드:
  - `ACTION:` 컷의 행동을 한국어로 간결하게 (동작 중간 순간, 진행형)
  - `CAMERA:` 영어 촬영 문법 한 줄 (wide low-angle burst, whip pan, crash zoom, rack focus, crane pan 등 — cinematography-glossary 준수, 컷당 무브 1개)
  - `DIALOGUE:` 대사 또는 `(…SFX)` 괄호 표기. 없으면 `없음`
- 스타일·팔레트·조명은 12컷 전체에서 통일. 캐릭터는 시트와 동일 인물로 전 컷 유지.

## 2. 선행 조건 — 캐릭터 시트 (영상 확장판)

스토리보드 전에 캐릭터 시트를 만든다. 영상 파이프라인용 시트는 turnaround-sheet.md 규격에 **동작·표정 패널을 추가**한 6패널 구성을 쓴다:

1. 정면(FRONT) 2. 3/4 3. 측면(SIDE) 4. 전신(FULL BODY) 5. 대표 동작 6. 표정(EXPRESSION — 기본/놀람/분노 등 3종)

- 5번 대표 동작 패널은 캐릭터 시그니처 액션으로 치환한다(실물 예: 러너는 달리기(RUN), 검객은 검술(SWORD ACTION), 서정 캐릭터는 상황 패널 — 처마밑(SHELTER)처럼 대표 신). 동작은 중간 순간·진행형으로.
- 배경 두 방식: 기본은 뉴트럴 시임리스, **세계관 통합형**은 전 패널 배경을 작품 무드(비 오는 도시 등)로 통일하고 상황 패널에 소품·제품 상호작용까지 넣는다(캠페인 세트용).

- 패널 표제는 렌더 허용(교육·참조용 시트이므로 무텍스트 규칙의 예외). 인물 컷 시트(마케팅 정체성용)는 기존 turnaround-sheet.md 7패널·무텍스트 규격을 유지한다 — 용도가 다르다.
- 실사 인물 파이프라인이면 5·6 패널의 동작·표정도 캐릭터 시트의 negativeConstraints를 준수한다.

## 3. 컷 설계 규칙

- 총량 먼저: 총 길이(예 15초)와 컷 수(12)를 헤더에 고정하면 컷당 호흡이 자동 결정된다(~1.25초/컷).
- 서사 아크: 도입(1–2) → 상승·장애물(3–8) → 클라이맥스(9–11) → 정착 히어로 프레임(12). 마지막 컷은 안정된 홀드로 끝낸다(persona-marketing CTA 프레임 원칙과 동일).
- 카메라 연속성: 원테이크 선언 시 인접 컷의 카메라 출구/입구가 이어져야 한다(컷 4 whip pan → 컷 5 vertical tilt처럼 방향 논리 유지).
- 환경 스토리텔링: 배경 요소(추격자 실루엣, 드론, 군중)는 2–3컷 간격으로 재등장시켜 연속성 앵커로 쓴다.
- 오디오 방침을 헤더에서 결정(BGM+SFX / SFX only / 무음)하고 DIALOGUE 필드가 그 방침을 따르게 한다.
- 콜드오픈 인서트: 컷1을 인물이 아닌 극단 매크로 훅(위협의 눈, 원두, 제품 표면 등)으로 열 수 있다 — 비인물 컷은 12컷 일관성 부담도 줄인다.
- 정적 비트: 질주 서사에도 1컷은 멈춤(뒤돌아보는 순간 정적 + 심장박동 SFX류)을 넣어 리듬을 만든다. SLOW-MO가 필요한 컷은 CAMERA 필드에 명시한다(컷당 1~2개 이내).
- ACTION은 필요 시 2행까지 허용(복합 동작). 무대사 보드는 DIALOGUE를 전부 `(…SFX)` 표기로 통일한다.
- 화면 인서트 통제(2026-07-08 NZ 3라운드 실측): 폰·모니터 컷은 양극단이 다 실패다 — 임의 UI(v1 실패)도, 텅 빈 화면+단어 하나(v2 과교정, 소품처럼 보임)도 부자연. 정답은 **현실적 앱 구성의 지정**: 흐릿한 말풍선 스레드·입력창 같은 실제 UI 골격을 서술하고, 지정 문구는 시스템 배너·말풍선 등 실제 위치에 배치한다. 자판 키캡 문자 금지, 화면 문자는 디스플레이 면에만, 임의 아이콘·상태바 금지는 유지.
- 폰 파지·연출(같은 실측): 폰을 카메라에 정면으로 펼쳐 보이는 **광고 목업 파지 금지** — 인물이 실제 쓰는 각도(몸 쪽 기울임, 비스듬, 화면에 약한 반사)로 지시한다. 인물이 읽는 화면을 관객에게 보여줄 땐 인물 시점 POV(내려다보는 자기 폰) 또는 어깨너머가 자연스럽다. 재연·일상 서사 보드는 각 컷 프레임에 캔디드 질감(생활 조명 불균일, 완벽하지 않은 구도)을 소량 지시해 스틸 광고컷화를 막는다.
- 반복 수정 세션 운용(2026-07-08 NZ-A/B 실측): 스토리보드 교정판 재생성은 **새 채팅(프롬프트 단독)이 기본**이다. 같은 대화에서 이어서 수정하면 직전 결과의 오류 패턴(조명 톤 등)이 프롬프트 수정을 이기고 상속된다 — 이어서 모드는 직전 결과가 거의 완성이고 미세 1~2요소만 조정할 때만 쓴다.
- 연출 상향 레버 3종(2026-07-08 MOA v1→v2 실측, 통제 축 회귀 없이 체감 상향 확인): ① **스케일 리듬** — 클로즈업·매크로 일변도 보드에 극단 와이드 1컷(도입부 권장)을 넣어 호흡 대비를 만든다. 와이드의 인물은 실루엣, 제품은 조명 앵커로만 써서 정체성·라벨 부담을 없앤다. ② **광 진행 서사** — 12컷을 같은 공간·같은 시간대로 두되 광량만 진행시킨다(예: 첫 햇살→골드→만개). '같은 아침이 밝아진다'처럼 연속 진행으로 서술하면 조명 통일 원칙과 충돌하지 않는다. ③ **살아있는 프레임** — seedance-2.md 첫 프레임 설계를 보드에 선제 이식: 전 컷을 동작의 중간 순간으로 강제하고 컷마다 환경 움직임 단서 1개(커튼 흔들림·부유 먼지·이동하는 그림자·흐르는 액체)를 넣는다. 클립 변환 적합도가 함께 올라간다.
- 캠페인 보드 크리에이티브 3규칙(2026-07-08 페이블5 FIZZ 8-3 vs MOA v2 비교 판독, v3 실전 투입 실측): ① **결핍 도입** — 광고 보드는 컷1~4에서 제품 없는 결핍 상태(지침·갈증·둔탁함)를 먼저 쌓고, 제품 개입 컷을 경계로 해방시킨다. 결핍 없는 보드는 광고가 아니라 무드필름이 된다(v3 실측 성립 — 결핍은 채도·광량·피부 컨디션으로만 표현하고 병색·다크서클 과장은 금지). ② **전환 장치는 과감하게** — 색·광·질감의 비포/애프터 진폭을 크게 잡는다(FIZZ: 무채색→풀컬러). 단 '뮤트 프레임 속 제품만 컬러' 같은 국소 전환은 실사에서 프레임 전체가 조기 웜 전환되며 미성립(v3 실측) — 실사 보드는 전환 경계를 컷 단위로만 잡고 프레임 내 부분 그레이딩은 기대하지 않는다. 동일 구도 비포/애프터 라임(예: 컷3↔컷10 같은 거울 구도)은 실사에서도 성립. ③ **그레이딩 주석을 캡션에** — 컷별 색·광 상태를 각 컷 ACTION 캡션 말미 괄호로 박는다. 주석 단어는 고유어·한자어를 쓴다((무채색)/(전환컷)/(풀컬러) 정상 렌더, 외래어 (뮤트)는 (유트)로 오탈자 실측) — 캡션에 있어야 클립 변환 시 컷별 지시로 그대로 따라간다.

## 3.5 캠페인 세트 (CF 파이프라인)

제품 광고 필름은 3종 세트로 만든다: **① 제품 시트**(turnaround-sheet.md 5.5) → **② 모델 시트**(2절, 상황 패널에 제품 상호작용 포함 가능) → **③ 스토리보드**(제품·모델 시트를 @ref로 첨부, 라벨 문구 일관 렌더). 페이블5 실물(FIZZ 캠페인: 제품 시트 + 우중 소녀 시트 + 광고 스토리보드)에서 확인된 구조다.

- 1차 실측(2026-07-08 MOA 세럼, gpt-image-2): 세트 3종 완주 통과. **자기 산출물 시트 2장만으로 참조 체인이 성립한다** — 스토리보드에 원본 인물 컷 없이 모델 시트(@ref2)만 붙여도 12컷 인물이 잠기고, 제품 시트(@ref1)는 매크로 컷(스포이드 끝 등 부분 노출)까지 디자인을 잠근다. 시트의 경미한 결함(시선 방향 등)은 스토리보드 컷 지시에서 재명시하면 상속되지 않는다.
- 모델 시트의 상황 패널(시그니처 액션)은 스토리보드 핵심 컷의 리허설로 쓴다 — 손-도구 물리와 표정을 시트에서 먼저 검증하면 보드에서 재발 위험이 줄어든다.

## 4. 컷별 클립 생성으로 변환

스토리보드 확정 후 각 컷을 클립 프롬프트로 변환한다:

- 컷 일러스트 = 첫 프레임 참조(@Image), ACTION = Subject/Action, CAMERA = Camera(무브 1개 그대로), 헤더 스타일 = Style, DIALOGUE = 오디오 지시.
- seedance-2.md 6단계 템플릿과 "영상용 참조 이미지 설계(첫 프레임)" 절을 적용한다. 컷 경계에서 인물 고정 제약문을 반복한다.
- 타 생성기(힉스필드 등) 사용 시에도 동일 구조로 변환 가능 — 어댑터 비목표 원칙은 유지하고, 변환 규칙은 이 문서와 seedance-2.md에만 둔다.

## 5. 자가점검 5항목

1. 헤더에 총길이·컷수·카메라 연속성 선언·오디오 방침이 모두 있는가.
2. 12컷 전체에서 캐릭터·스타일·조명이 같은 작품으로 읽히는가.
3. 컷마다 ACTION/CAMERA/DIALOGUE 3필드가 채워졌고 카메라 무브가 컷당 1개인가.
4. 인접 컷의 카메라·동선이 논리적으로 이어지는가(원테이크 선언 시).
5. 소품 연출 자연성: 폰·도구가 실제 사용 각도로 읽히는가 — 카메라 제시형 파지, 소품용 빈 화면이 없는가.
