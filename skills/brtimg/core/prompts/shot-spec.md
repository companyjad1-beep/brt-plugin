# 샷 스펙 선택 규칙 (shot-spec)

이 문서는 장면 프롬프트의 시각 요소를 축(axis) 단위로 선택하게 하는 guided 절차와 축 카탈로그를 정의한다. `/brtimg:build` 커맨드와 GUI 빌더가 공유하는 단일 소스다. 어휘는 `core/style-library/cinematography-glossary.md`를 기준으로 하고, 이 문서는 선택 구조와 세분화만 담당한다.

## 1. 원칙

- 선택 결과는 최종 프롬프트가 아니라 **샷 스펙 브리프**다. 브리프는 `loop.md`의 초안→비평→개선 루프에 입력되어 자연문으로 조합된다. 선택값을 기계적으로 이어붙여 최종본으로 내지 않는다.
- 모든 축은 **패스 가능**하다. 패스한 축은 루프가 도메인·생성기 기준으로 판단하고, 판단 근거를 설계메모 `assumptions`에 남긴다.
- 인물 외모 축(얼굴·눈·입술·피부·헤어·체형·고유 마커)은 이 문서에 없다. 캐릭터 시트(`workspace/characters/*.yaml`)에서 가져오며, 시트가 없으면 `appearance-catalog.md`로 먼저 만들거나 사용자 서술만 사용한다.
- guided 진행은 `conversational`의 3라운드 제한을 따르지 않는 별도 흐름이다. 단, 저장되는 프롬프트 파일의 `modes`에는 스펙 수집 후 자동 완주하므로 `oneshot`을 기록한다(스키마 enum 유지).
- 각 축에서 사용자는 제시된 프리셋 외의 자유 서술을 넣을 수 있다. 프리셋은 어휘 앵커일 뿐 제한이 아니다.
- 딥 디컴포지션: 충실도(fidelity)가 중요한 요청(리슛·인물 화보·레퍼런스 재현)에서는 `core/prompts/deep-decomposition.md`를 함께 읽어 fidelity anchors(§1)·anchor-per-field(§2)·composition map(§3)·교차필드 정합(§6)을 브리프에 반영한다. 필드 구조는 `core/schema/image-prompt-template.json`.

## 2. guided 진행 방식

한 라운드에 한 묶음씩 묻는다. 각 라운드는 축 이름 + 프리셋 선택지 + "패스" 옵션으로 제시한다. 이미지 5라운드, 영상이면 6라운드째를 추가한다.

1. 라운드 1 — 프레임: 방향·종횡비, 샷 사이즈, 인물 배치, 여백.
2. 라운드 2 — 카메라: 방위, 높이, 앵글, 렌즈 느낌.
3. 라운드 3 — 피사체: 몸 방향, 얼굴 방향, 시선, 자세·손 (표정·외모는 캐릭터 시트/사용자 서술).
4. 라운드 4 — 조명: 키 방향, 패턴, 광질, 보조광, 키·대비, 색온도·시간대.
5. 라운드 5 — 마감: 초점·심도, 색·질감, 배경, 네거티브.
6. 라운드 6 — 영상 전용: 카메라 움직임, 속도·리듬, 피사체 동작, 시간 조작, 샷 길이.

사용자가 "나머지 전부 패스"라고 하면 즉시 라운드를 종료하고 브리프를 확정한다.

## 3. 축 카탈로그 — 이미지 공통

### 3.1 프레임

- 방향·종횡비: 세로 9:16 / 세로 4:5 / 세로 3:4 / 세로 2:3 / 정방형 1:1 / 가로 4:3 / 가로 3:2 / 가로 16:9 / 가로 2.39:1 시네마스코프.
- 샷 사이즈: 극단적 클로즈업(ECU) / 클로즈업(CU) / 반신 클로즈업·바스트 샷(머리~가슴 위) / 미디엄 클로즈업(MCU, 어깨 위) / 미디엄 샷(MS, 허리 위) / 미디엄 롱 샷(MLS, 무릎 위) / 롱 샷(LS, 전신) / 익스트림 롱 샷(ELS).
- 인물 배치: 정중앙 / 중앙보다 약간 왼쪽·오른쪽 / 좌 1/3 / 우 1/3 / 하단 1/3 / 대각 배치.
- 여백: 헤드룸(타이트/클린/넉넉) / 리드룸·노즈룸(시선·이동 방향 앞 공간) / 카피 여백(좌/우/상/하) / 네거티브 스페이스 강조.
- 구도 장치: 삼분법 / 중앙 대칭 / 황금비 / 리딩 라인 / 대각선 구도 / 삼각 구도 / 프레임 인 프레임(문·창·거울) / 전경 레이어(전경 흐림 오브젝트) / 반사 대칭(수면·거울) / 실루엣 / 비네팅 중앙 집중.

### 3.2 카메라

- 방위(피사체 기준 수평 위치): 정면 / 전면 사선(3/4 프론트) / 측면(프로필) / 후면 사선(3/4 백, 등·어깨가 먼저 보임) / 정후면.
- 높이: 지면 레벨 / 무릎 / 허리 / 가슴 / 눈높이 / 머리 위.
- 앵글: 웜즈아이(극단적 로우) / 로우 앵글 / 살짝 로우(턱선 아래) / 아이레벨 / 살짝 하이(이마 위) / 하이 앵글 / 오버헤드·탑샷 / 버즈아이(수직 부감) / 더치 앵글 약(5~10도) / 더치 앵글 강(20도+) / 오버 더 숄더(OTS) / POV / 거울·반사 시점.
- 렌즈 느낌: 초광각·피시아이 / 24mm 와이드 / 35mm 라이프스타일 / 50mm 노멀 / 85mm 인물(배경 압축) / 135mm+ 망원 압축 / 마크로(접사) / 아나모픽(타원 보케·수평 플레어).
- 거리감: 밀착(프레임 꽉 참) / 표준 / 관찰자 거리(멀찍이).

### 3.3 피사체 방향·포즈

- 몸 방향: 정면 / 3/4 / 측면 / 후면 사선 / 정후면.
- 얼굴 방향: 몸과 동일 / 렌즈 쪽으로 돌림(돌아보기, looking back over shoulder) / 프로필 유지 / 아래·위로.
- 시선: 렌즈 직시 / 카메라를 살짝 비껴봄 / 오프카메라 좌 / 오프카메라 우 / 아래(다운캐스트) / 위로 / 감은 눈 / 제품·소품 응시 / 화면 밖 원경.
- 자세·손: `persona-marketing.md` 2.3의 포즈·손 규칙을 따른다. 프리셋: 팔짱 / 턱 괴기 / 제품 들기(라벨 정면) / 주머니 손 / 걷는 중 / 앉음 / 기대기 / 머리카락 넘기기 / 옷깃·소매 정리 / 컵·소품 감싸쥐기 / 어깨 너머 돌아서기 / 양손 모으기.

### 3.4 초점·심도

- 초점 우선순위: 서열로 지정한다. 예: `눈 > 안경 > 입술 > 어깨 > 귀·배경`. 기본값은 인물 컷에서 항상 `눈` 최우선.
- 심도: 극얕은(눈만 선명) / 얕은(얼굴 선명·배경 분리) / 중간 / 깊은(팬포커스, 전경~배경 선명).
- 기법: 소프트 포커스(전체 부드럽게) / 스플릿 디옵터(전경·후경 동시 선명) / 보케 성격(크림 같은/원형/아나모픽 타원).

### 3.5 조명

- 키 방향: 시계 방위(정면 12시 기준 좌상 10~11시, 우상 1~2시, 측면 3시/9시, 후면 5~7시) + 높이(눈높이/45도 위/바로 위/아래).
- 패턴(인물 표준 6종 + 수정자): 플랫(정면 균일) / 버터플라이·파라마운트(코 밑 나비 그림자, 뷰티 표준) / 클램셸(버터플라이+하단 필, 피부 최상) / 루프(코 옆 작은 고리 그림자, 만능) / 렘브란트(볼에 삼각 하이라이트, 드라마) / 스플릿(반명반암, 최대 드라마). 수정자: 브로드(카메라 쪽 면을 밝게, 얼굴 넓어 보임) / 쇼트(먼 쪽 면을 밝게, 갸름해 보임).
- 광질: 하드(선명한 그림자 경계) / 소프트(부드러운 경계) / 확산(그림자 최소).
- 보조광: 필 라이트(강/약/없음) / 림 라이트 / 백라이트·헤어라이트 / 언더라이트(아래에서, 긴장감) / 실용광(장면 내 조명기구) / 모티베이티드(창문 등 자연 광원 정당화).
- 키·대비: 하이키(밝고 그림자 적음) / 미드 / 로우키(어둡고 대비 강함). 대비: 낮음(매트) / 중간 / 높음(치아로스쿠로).
- 색온도·시간대: 웜(3200K 텅스텐) / 뉴트럴(4800~5600K 주광) / 쿨(7000K+) / 골든아워 / 블루아워 / 정오 직사 / 흐린 날 확산 / 야간 네온·가로등 / 창가 자연광 / 촛불·모닥불 / 믹스드(웜 키+쿨 배경).
- 하이라이트 성격: 둥글고 부드러운 스펙큘러 / 날카로운 스펙큘러 / 크림빛 브로드 하이라이트.

### 3.6 색·질감·마감

- 팔레트: 웜 톤 / 쿨 팔레트 / 뉴트럴 / 파스텔 / 저채도(뮤티드) / 모노크롬·흑백 / 세피아 / 틸 앤 오렌지 / 핑크-그레이 / 크림·아이보리 / 브랜드 컬러 지정.
- 그레인·매체감: 무그레인 디지털 클린 / 미세 그레인 / 35mm 필름 / 중형 포맷 룩 / 폴라로이드·즉석사진 / 빈티지 프린트 / CCD 디지털캠(2000년대) / VHS·8mm 홈비디오.
- 스타일 질감: 상업 화보(커머셜) / 에디토리얼 / 다큐멘터리 / UGC·폰카 / 시네마틱 스틸 / 일러스트레이션 / 아이돌 화보 / 스트리트 스냅 / 필름 누아르.
- 마감: 매트 / 세미글로시 / 글로시. 샤프닝: 자연스러움 유지(과한 샤프닝 금지 기본).

### 3.7 배경·환경

- 유형: 단색 시임리스 / 그라데이션 벽 / 스튜디오 세트 / 실내 실장소 / 야외 / 추상 텍스처 / 보케 라이트(야경 불빛) / 커튼·패브릭 / 식물·플로럴.
- 밀도: 완전 미니멀(인물 외 요소 없음) / 소품 1~2개 / 생활감 / 복잡한 환경.
- 처리: 선명 / 흐림(보케) / 실루엣화.

### 3.8 네거티브(피할 것)

기본 제공 목록에서 선택·추가: 과한 샤프닝 / 하드 섀도우 / 복잡한 배경 / 진한 메이크업 / 얼굴 왜곡 / 기름진 번들거림 / 고대비 / 손 왜곡 / 추가 인물 / 워터마크·텍스트 / 플라스틱 피부 / 과노출 / 색수차 / 치아 보임. 생성기별 금지문은 `core/generators/*.md`를 따른다.

## 4. 축 카탈로그 — 영상 전용

이미지 축 전체를 상속하고 아래를 추가한다.

### 4.1 카메라 움직임

고정(스태틱·락드) / 팬 / 윕 팬(고속, 모션 블러) / 틸트 / 달리 인(푸시인) / 달리 아웃(풀아웃) / 트럭·크랩(측면 평행 이동) / 페데스탈(카메라 자체 상하 이동) / 트래킹(피사체 추적) / 아크·오빗(호 궤도) / 크레인·붐 업·다운 / 에어리얼·드론 / 핸드헬드(자연 흔들림) / 스테디캠·짐벌(부드러운 이동) / 줌 / 돌리 줌(베르티고, 원근 왜곡) / 랙 포커스(초점 이동).

`seedance-2` 요청에서는 한 샷에 주 움직임 1개만 둔다(`modes.md` 충돌 해결 규칙). 돌리 줌·윕 팬처럼 왜곡·블러를 만드는 움직임은 인물 정체성 안정성과 상충하므로 선택 시 경고를 브리프에 남긴다.

### 4.2 움직임 속도·리듬

아주 느리게(subtle) / 느리게 / 보통 / 빠르게. 리듬: 일정 / 점진 가속 / 점진 감속.

### 4.3 피사체 동작

정지(포즈 유지) / 미세 동작(머리카락 날림·눈 깜빡임·미소 번짐) / 손 동작(제품 들어올림·바름·시연) / 걷기·회전 / 카메라를 향해 돌아봄.

### 4.4 시간 조작

실시간 / 슬로모션 / 타임랩스 / 스피드 램프(속도 변화, 컷 없이 느림→빠름→느림).

### 4.5 샷 구조

길이(초) / 시작 상태 → 중간 → 종료 상태 2~3단계 요약(`modes.md` 영상 참고 규칙과 동일한 형식) / 루프 가능 여부(시작·끝 상태 일치).

## 5. 충돌·정합 규칙

브리프 확정 전에 다음을 점검하고, 충돌이 있으면 사용자에게 1회 확인하거나 우선순위 규칙으로 해소한다.

1. 후면 사선·정후면 방위 + 렌즈 직시 시선 → 돌아보기(looking back) 포즈가 필수로 함께 지정되어야 한다.
2. 버즈아이·오버헤드 + 렌즈 직시 → 인물이 위를 올려봐야 하므로 목 각도가 부자연스러울 수 있다. 확인 후 진행.
3. 24mm 이하 와이드 + 얼굴 근접(CU 이상) → 얼굴 왜곡 위험. 85mm 인물 렌즈 대체를 제안한다.
4. 스플릿·렘브란트(드라마 패턴) + 하이키 → 상충. 패턴을 유지하려면 미드~로우키로 조정.
5. 얕은 심도 + 텍스트·라벨 가독성 요구 → 라벨이 초점면에 오도록 초점 우선순위를 조정.
6. 더치 앵글 + 제품 안정성 요구 → 지양 제안(용어집 규칙).
7. 영상: 카메라 움직임 2개 이상 선택 → 주 움직임 1개만 남기고 나머지는 변형(variants)으로 분리.
8. 시리즈 문맥: 캐릭터 시트의 `identityAnchors`·`negativeConstraints`와 충돌하는 선택(예: 시그니처 안경 제거)은 시트가 우선한다(`series-injection.md`).

## 6. 브리프 출력 형식

선택이 끝나면 아래 형식의 브리프를 만들고 사용자에게 확인받은 뒤 루프에 입력한다. 패스한 축은 쓰지 않는다.

```text
샷 스펙 브리프
- 매체: 이미지 | 영상 / 타깃 생성기
- 캐릭터: workspace/characters/….yaml (없으면 "시트 없음")
- 충실도 앵커(fidelity 5~8, 랭킹): [이 컷을 이 컷이게 하는 요소 — deep-decomposition §1, 해당 시]
- 프레임: [선택값들]
- 카메라: [선택값들]
- 피사체: [선택값들]
- 조명: [선택값들]
- 마감: [초점·심도 / 색·질감 / 배경]
- 컴포지션 맵(해당 시): [프레임 크롭·전/중/후경·3분할·엣지 접촉 — deep-decomposition §3]
- 네거티브: [목록]
- (영상) 움직임: [주 움직임 1개 + 속도] / 동작: […] / 시간: […] / 샷 구조: […]
- 충돌 점검: [해소 내역 또는 "없음"]
```

## 7. 자가점검 3항목

1. 축 순수성: 브리프에 인물 외모 서술이 섞이지 않았는가(외모는 시트 몫).
2. 충돌 해소: 5절 규칙을 모두 점검하고 결과를 브리프에 남겼는가.
3. 루프 통과: 최종본이 브리프 선택값을 전부 반영하되 나열이 아닌 자연문으로 조합되었는가.
4. 충실도 앵커: fidelity가 중요한 컷이면 5~8개 앵커를 랭킹으로 잡아 브리프·finalText 앞에 우선 배치했는가. 각 서술에 구체 앵커(숫자·각도·명명색)가 있는가(무드어 단독 금지).
