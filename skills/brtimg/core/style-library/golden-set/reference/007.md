# 007 — 드래곤 변신 시퀀스 (5섹션 템플릿+변신 연속성 단서)

- 대상 생성기: seedance-2
- 출처: https://www.xazinga.com/post/39ee2f8d-2c56-46e0-8cca-39583d8b22b9 (XAZINGA)
- 기법 노트: [소재 바인딩]/[피사체+공간]/[타임라인]/[카메라+오디오]/[스타일+제약] 5섹션 헤더 템플릿 — core/generators/seedance-2.md 권장 구조와 동형. 변신 전후 동일 존재임을 "금색 눈동자"라는 연속성 단서 하나로 고정하는 기법, 스케일 대비를 위해 "변신 전후 컷에 인간 크기 기준물 배치" 지시, 구간별 카메라 무브를 타임라인과 1:1 대응시키는 설계가 핵심.

## 프롬프트

[소재 바인딩] @이미지1 = 하린(은발 미디엄 헤어, 흰 판타지 드레스, 은장식 숄더 아머, 블랙 사이하이 부츠). 인간 폼 외형을 @이미지1과 완전히 일치. @이미지2 = 골드 드래곤(황금 비늘, 어깨 높이 약 150m, 날개 폭 250m, 세로 동공의 금안). 드래곤 폼 외형과 비늘 질감, 두상, 발톱을 @이미지2와 완전히 일치. 하린과 골드 드래곤은 동일 존재 — 변신 전후 금색 눈동자가 연속성의 단서. [피사체 + 공간] 황혼의 폐허 평원. 무너진 요새 잔해와 창을 든 마물 대군이 지평선까지 깔려 있고, 낮게 깔린 구름이 붉은 노을을 머금었다. 인간 폼 하린은 대군 정중앙에 홀로 서 있다 — 흰 드레스가 잿빛 전장에서 유일하게 밝은 점. [타임라인] 0-2초: 첫 프레임 — 핸드헬드 극단, 마물 하나가 하린의 얼굴을 향해 창을 내지르는 초근접 — 하린은 피하지 않고 눈을 감으며 길게 숨을 내쉰다. 내쉰 숨이 금빛 입김으로 번지고, 목덜미와 쇄골의 피부 아래에서 용암이 비치듯 황금 균열이 실핏줄처럼 번진다. 창끝이 닿기 직전 정지 — 그녀의 눈이 뜨이면 세로 동공. 2-5초: 홀리모프 역변신 — 하린을 중심으로 황금빛 기둥이 수직으로 폭발, 충격파 링이 지면의 먼지를 원형으로 밀어내며 최전열 마물들이 낙엽처럼 날아간다. 카메라가 초고속 크레인 풀백 — 빛기둥 안에서 실루엣이 수십 배로 부풀며 골격이 재구성되고, 빛이 걷히는 순간 어깨 높이 150미터의 골드 드래곤(@이미지2)이 250미터 날개를 펼쳐 노을을 통째로 가린다. 날개 그림자가 대군 위로 일식처럼 덮인다. 5-8초: 윙 블라스트 + 터레인 컨트롤 체인 — 날갯짓 단 한 번에 압축된 폭풍이 부챗살로 퍼지며 전열이 통째로 쓸려나가고, 흙먼지가 수백 미터 벽처럼 일어선다(윙 블라스트) / 앞발톱이 대지를 움켜쥐자 지각이 융기, 황금 광맥이 박힌 암벽들이 대군의 퇴로를 원형 투기장처럼 봉쇄한다(터레인 컨트롤). 마물들이 도망칠 곳 없이 중앙으로 몰린다. 전 컷 격렬한 핸드헬드, 화면에 먼지와 파편 상시. 8-11초: 라이트 브레스 — 드래곤의 가슴 비늘 틈새가 안쪽에서부터 순차적으로 점등된다, 용광로의 쇳물이 비늘 사이로 비치듯. 목이 부풀고 고개가 젖혀졌다가 — 응축된 백금색 빛의 브레스가 지면을 일직선으로 훑는다. 화염이 아니라 빛 그 자체: 닿은 마물은 타지 않고 빛 입자로 분해되어 위로 흩어지고, 브레스가 지나간 자국은 유리처럼 녹아 굳은 황금 유리의 직선. 부감으로 투기장 안이 빛의 궤적으로 십자 소거된다. 11-13초: 모순의 앵커 — 빛 입자가 눈처럼 내려앉는 정적 속, 완전 고정 카메라로 드래곤의 눈 익스트림 클로즈업 2초: 세로 동공의 금안에 소멸하는 전장이 비치고, 느릿한 눈 깜빡임 한 번, 콧김 한 번. 굉음이 먹먹해지고 거대한 심장 박동의 저역만. 13-15초: 역재생 홀리모프 — 거체가 빛으로 붕괴하며 안쪽으로 접혀들고, 빛이 꺼진 자리의 황금 유리 원 중앙에 인간 폼 하린이 서 있다. 흐트러진 은발을 손으로 한 번 넘기고 아무 일 없었다는 듯 걸어 프레임 밖으로 — 카메라는 따라가지 않는다. 빈 유리 바닥 위, 떨어져 있는 황금 비늘 한 장의 매크로 — 비늘에 노을이 비치며 종료. [카메라 + 오디오] 0-2초 핸드헬드 초근접 → 2-5초 초고속 크레인 풀백 → 5-8초 격렬한 핸드헬드 + 먼지 파편 → 8-11초 브레스 라인을 따라가는 측면 고속 트래킹, 이후 부감 → 11-13초 완전 고정 → 13-15초 고정, 인물이 프레임을 떠나게 둔다. 스케일 대비가 핵심 — 변신 전후 컷에 반드시 인간 크기 기준물(마물, 잔해)을 함께 배치. 오디오: 0초 창 내지르는 파공음과 마물 포효로 후킹 → 숨 내쉬는 소리, 피부 균열의 유리 갈라지는 미세음 → 변신 폭발의 초저역 충격파 + 성가대 한 음 → 날갯짓의 대기 찢는 굉음, 지각 융기의 암반 파열 → 브레스 차징의 공명음이 고조되다 발사 순간 모든 소리가 빨려나가고 순수한 톤 하나만 지속 → 정적, 심장 박동 저역과 콧김 → 역변신의 빛 감기는 소리 → 또각또각 멀어지는 부츠 발소리, 비늘 위 바람 소리로 끝. [스타일 + 제약] 시네마틱 다크 판타지, 황혼의 웜톤과 황금 발광의 이중 골드 팔레트, 볼류메트릭 라이트, 하이 콘트라스트. 2.35:1, 필름 그레인. 빠른 리듬의 컷 편집, 비트 동기화 전환. 지정된 컷 구분만 사용, 임의 전환 금지.
