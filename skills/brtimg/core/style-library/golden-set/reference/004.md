## 프롬프트

업로드한 이미지의 메인 피사체를 분석해서 귀여운 레트로 픽셀 아이콘으로 재구성해줘. 1. 주제 판별 (사람/동물/음식/사물) 2. 핵심 실루엣과 색감 추출 3. 레트로 게임 스프라이트 스타일로 변환 픽셀: 크고 선명한 도트, 블러 없음, Aseprite 느낌. 색감: 원본 기반 레트로 팔레트, 흰색 배경. 구도: 중앙 1:1 정사각형, 주제 60~75%. 금지: 3D 렌더, 복잡한 배경, 음식에 얼굴.
