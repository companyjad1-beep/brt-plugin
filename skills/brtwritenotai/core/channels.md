# 채널·스타일 — 포맷 프로파일 + 말투 + Voice Card/프리셋 적용

## 스타일 적용 우선순위

**Voice Card > 문체 프리셋 > 채널 기본.** 음화 금지(rulebook 1부)는 항상 이 셋보다 우선하되, Voice Card와 quick-rules가 충돌하면 카드 우선(사용자의 실제 습관이 곧 사람 티) — 단 이중 피동·"~에 대해" 같은 오류형 번역투(S1 A군)는 예외로 고친다.

- **Voice Card**: `_workspace/brtwritenotai/voice-card.md`가 있으면 문체 스펙으로 적용.
- **문체 프리셋**: 요청에 "팩트축적식으로(분석·시세)/사유전개식으로(에세이)/체험일기식으로(캐주얼 리뷰)/동료화법식으로(커뮤니티)/문제해소식으로(비교·가이드)/안내문식으로(공지)/판매카피식으로(상세·랜딩)"가 있으면 `core/style-presets.md`의 해당 프리셋을 적용한다. 지정 없으면 채널·주제로 권장 프리셋을 골라 산출물에 어떤 프리셋을 썼는지 명시한다.

## 말투(존대 단계) 우선순위

① 요청에서 지정("해요체로", "반말로", "합니다체로", "개조식으로")이 최우선 ② 없으면 Voice Card의 말투 ③ 그것도 없으면 채널 기본 — blog·instagram=해요체, thread=평어/반말 톤 허용, reply=상대 문체 따라감.

종결어미 변주는 **선택된 말투 안에서** 한다(해요체면 ~요/~죠/~거든요/~더라고요/명사 종결 섞기, 개조식이면 ~임/~함/~봄/명사 종결 — 말투를 바꾸는 게 아니라 같은 말투의 종결을 굴리는 것). 한 글 안 말투 혼용 금지(quick-rules E-7), 단 반말 조각문 1~2개("이건 함정.")는 사람 티로 허용.

## 포맷 프로파일 (요청·채널로 자동 판별, 애매하면 물어본다)

| 포맷 | 작성 규칙 | 게이트 |
|---|---|---|
| **blog / 커뮤니티 메인글** (기본) | 풀 구조: 실측 시작·판단·소제목 2~3개·제목 후보. 네이버 블로그면 문단을 1~3문장으로 잘게 끊고 빈 줄로 호흡(모바일 가독 리듬) | 풀 게이트 ①~⑤ |
| **thread (쓰레드/X)** | 첫 문장 = 훅(실측 숫자·통념 반박), 문장 짧게, 1포스트 1주장, 해시태그 0~2개, 이모지 스택 금지 | 숏폼 게이트(스팬 스캔만) |
| **instagram 캡션** | 첫 줄(더보기로 접히기 전)이 승부 — 실측 디테일 1개로 시작, 본문 3~6줄, CTA 한 줄, 해시태그는 본문 끝에 분리. 캐주얼 톤이면 기대→배신→수용 미니 서사·셀프토크("왜지?") 허용 — 좋은 것만 나열하면 광고 티 | 숏폼 게이트 |
| **reply (답글·댓글)** | 상대 글의 **구체 지점을 집어서** 시작(어느 댓글에나 붙는 범용 답변 금지), 템플릿 문구 금지("소중한 의견 감사합니다"·"많은 관심 부탁드립니다" = CS 봇 티), 상대 문체(존댓/반말·톤)에 맞춤, 2~5문장, **가장 아픈 지점 1개만 치고 빠진다**(음화 32 풀코스 완결성 금지) | 숏폼 게이트. Phase 1 완화: 주제=상대 글, 독자=상대방으로 자동 충족, 실측 디테일은 권장이되 필수 아님(대화 맥락이 소재) |
